GIFT UP v6 — демонстрационный сайт

Запуск на Windows:
1. Открой PowerShell в папке GIFT_UP_v5
2. Выполни: py -3.12 -m pip install -r requirements.txt
3. Выполни: py -3.12 app.py
4. Открой http://127.0.0.1:5000/

Что обновлено:
- Шанс апгрейда теперь считается по формуле: стоимость исходного подарка / стоимость цели * 100%.
- Индикатор показывает сектор вероятности, стрелка останавливается в случайной точке круга, а победа/проигрыш определяется той же точкой. Поэтому частота побед математически соответствует показанному проценту.
- Добавлен визуальный выбор исходных подарков из инвентаря и большой каталог из 28 демонстрационных карточек, включая NFT-стиль, редкие и обычные категории.
- Добавлены фильтры каталога.

ВАЖНО: это демонстрационный проект. Карточки NFT — иллюстративные макеты, не реальные Telegram NFT-подарки и не подтверждение владения ими. Кейсы, баланс, продажа и апгрейд работают только в браузере. Реальные FlexStar-платежи, выводы, переводы подарков и авторизация FlexGram не подключены. Данные демо-сессии не являются настоящими средствами.
